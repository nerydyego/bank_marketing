# Projeto de Machine Learning - Bank Marketing

## Problema

Desenvolver um modelo de Machine Learning capaz de prever se um
cliente de uma instituição bancária irá contratar um depósito a prazo
a partir de suas características e informações disponíveis antes da
decisão.

## Tipo de problema

- Aprendizado: Supervisionado
- Tarefa: Classificação
- Tipo: Classificação binária
- Variável alvo: `y`
- Classes: `yes` e `no`

## Objetivo

Construir, avaliar e comparar diferentes algoritmos de classificação
para identificar clientes com maior probabilidade de contratar um
depósito a prazo.
